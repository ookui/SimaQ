# Markdown 渲染覆盖情况

参考：[Typora Markdown Reference](https://support.typora.io/Markdown-Reference/)（2026-10-31 更新）。「源码」表示切换源码模式或激活对应块后可访问原始文本；保存沿用编辑器的原文保存路径。此表说明当前实现，不表示与 Typora 完全一致。

| 功能 | 显示 | 可视化编辑 | 源码 | 保存 |
| --- | --- | --- | --- | --- |
| 标题、段落、引用、列表、强调、删除线 | Markdown-it 渲染，标题支持 1—6 级 | 激活块后编辑源码 | 保留 | 保留原文 |
| 任务列表 | 复选框和列表 | 点击复选框；其余内容编辑源码 | 保留 | 保留原文及勾选修改 |
| 表格 | 表格组件 | 单元格及表格工具 | 保留 | 按表格组件更新 |
| 行内链接、引用链接、双链 | 显示链接；定义行显示源码 | 激活块编辑源码 | 保留 | 保留原文 |
| 脚注 | 单行定义可显示引用提示；定义行显示源码 | 激活块编辑源码 | 保留 | 保留原文 |
| 代码块 | 支持常见语言的语法高亮；未知语言显示纯文本 | 激活块编辑源码 | 保留 | 保留原文 |
| 行内与块数学公式 | 本地 MathJax 4.1.0 输出 SVG，按需加载随附的 STIX 字形；支持 AMS 编号、跨段正反向引用和离线 HTML 导出 | 激活块编辑源码 | 保留 | 保留原文 |
| Mermaid | 本地严格模式异步绘图；无效图表显示源码 | 激活块编辑源码 | 保留 | 保留原文 |
| HTML 片段 | 保留不带属性的常见格式标签；其余显示为文本 | 激活块编辑源码 | 保留 | 保留原文 |
| YAML 元数据 | 源码及折叠控件 | 激活块编辑源码 | 保留 | 保留原文 |
| `[toc]`、`==高亮==`、`^上标^`、`~下标~` | 目录、标记及上下标 | 激活块编辑源码 | 保留 | 保留原文 |
| Emoji 简写、告警块 | 显示原始语法 | 激活块编辑源码 | 保留 | 保留原文 |

单元测试 `node Web/editor/render.test.cjs` 覆盖源码位置、一级标题、表格、链接、跨文档引用、脚注、任务列表、代码转义、安全 HTML、图片路径、目录、高亮、上下标和数学块识别。浏览器内视觉效果、复选框交互、图表及导出效果需结合应用测试；脚注尚不支持多段和嵌套定义，目录及上下标解析未覆盖 Typora 的全部边界语法。

库文件来自本机 Cursor 的 Markdown-it、本机 Typora 的 MathJax 与 Mermaid，以及本机 npm 缓存的 highlight.js。各依赖及许可证位于 `Web/editor/vendor`。
