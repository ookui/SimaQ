SimaQ 使用说明

首次打开请选择“示例资料库”，或按 ⌘O 选择已有的本地文件夹。示例库会复制到可编辑目录，可放心试写。

用一份公司笔记开始

  1. 打开「公司 / 富瀚微.md」。表格中点选单元格，用 Tab 前进。复制三行两列的电子表格数据，粘贴到第一个目标单元格，用 ⌘Z 撤销。
  2. 按 ⌘⇧F 输入 physical ai。展开「归档 / 2025 / 富瀚微.md」，选择第二处命中。精确短语保留查询中的分隔符。
  3. 在公司笔记中按 ⌘K，输入“视觉”，选择 HTML 报告。打开报告后，点其中的“阅读访谈纪要第 2 页”。用工具栏的后退按钮返回。
  4. 在「设置」切换浅色或深色外观。将表格字号调小，留意正文和左栏字号。点击页首的小号斜体 YAML 可编辑原文。

菜单默认采用 macOS 首选语言。在「SimaQ → Settings… → General → Menu Language」（⌘,）可选择跟随系统、English、简体中文或繁體中文。选择立即生效，并在下次启动时保留。

日记目录

在「文件 → 日记目录…」选择当前工作区的根目录或子目录。设置按工作区保存。侧栏「今天」会打开所选目录的日历，列出该目录及其子目录中的日记。首次编辑某天的新日记时，文件会保存到所选目录。更改设置不会搬动旧文件。未配置的资料库继续自动识别 LifeOS/journals。

阅读与引用

在左侧目录中单击文件会替换当前标签页。按住 ⌘ 点击，或右键选择「在新标签页中打开」，可保留当前页面。目标文件已经打开时会切换到已有标签页。

右侧大纲随正文滚动，高亮阅读区域中线所在的章节。点击大纲标题后，正文在标题上方留出约两到三行，按 ⌘⇧O 可收起或展开大纲。

页首沿用左侧一级目录的配色。标题下方的小标签显示笔记所在的目录，例如 Sources/companies 下的笔记显示 # companies。YAML 默认收起；将鼠标移到标题上方的细线可预览，移出元数据栏即收起。点击内容可编辑，点击细线可固定或收起。

Markdown 页底的「引用此页」按来源笔记列出链接所在段落。点击段落，跳转到来源行。新增或修改笔记后，引用随索引更新。第一次打开旧资料库时会重建索引，期间结果会陆续出现。

搜索、主题与 Markdown

搜索侧栏按文件分组。右侧数字统计正文命中次数，包含标题。同一行出现两次计两处。仅文件名或路径匹配时计为 0，仍可点开文件。每组先显示五处，点击组标题折叠，点击下方按钮展开更多。

在「文件 → 工作区排除目录」添加或移除子目录。每个工作区单独保存，默认隐藏根目录下的 _Meta。取消排除后会重新建立该目录的搜索索引。

在「主题 → Tana Light」启用 Typora 的 Tana 配色。字号、字体、表格和 YAML 样式在「主题 → 主题设置」调整。自定义 CSS 放在 ~/Library/Application Support/SimaQ/Themes/，可在设置中打开此目录。

LaTeX 行内公式写作 $E=mc^2$ 或 \(E=mc^2\)。独立公式使用 $$…$$ 或 \[…\]，定界符可另起一行。点入公式所在段落编辑源码，离开段落后显示排版。格式和段落菜单分别提供行内和独立公式。

在「文件 → Markdown 图片目录」选择基准目录，填写 images 或 ${filename}.assets 并保存。默认基准为笔记所在目录。新粘贴的图片写入所选目录。已有图片链接优先按原路径读取，找不到时从图片目录补找，例如 分析.md 中的 ![图](趋势.png) 可读取 images/趋势.png。

正文支持相对路径图片和 ![[图名.svg]] 嵌入。单击图片，在正文中图片上方直接编辑该处的 Markdown 写法。双击图片按原始尺寸打开前景预览，原图宽度或高度超出预览框时显示减号，单击缩至完整显示，再点恢复 100%。原图能完整放下时显示加号，单击放大至 200%，再点恢复 100%。也可用 ⌘＋滚轮、触控板捏合或加减按钮缩放，按住图片拖动可平移，按 Esc 回到原处。图片文件名可以含空格。将鼠标移到图片上，左右拖动图片底角的 ↔ 即可等比缩放，双击 ↔ 恢复原尺寸。宽度以像素写在该处图片链接后，例如 ![趋势](images/趋势.png){width=360}。右键点击图片可复制图片、导出本地原图，或选择图片居左、居中、居右。导出保留原文件的格式和分辨率。同一图片在不同位置可分别设置，例如 ![趋势](images/趋势.png){width=360}{align=center}。

图片与数据文件

打开 SVG 时默认等比适应预览框，小图会自动放大，大图会缩小以完整显示；改变预览框大小时自动重新适配。仅设置 viewBox 的 SVG 按其坐标尺寸作为 100% 的参考，避免浏览器的默认小尺寸影响预览。

在「视图 → 滚动速度…」（View → Scrolling Speed…）可分别设置鼠标滚轮和触控板速度，范围为 0.5×—3×，修改立即生效并保存。鼠标默认 1.5×，触控板默认 1×；选择 1× 使用系统速度。设置作用于侧栏、正文及图片预览，⌘＋滚轮缩放保持独立。也可在设置的「常规」中调整。

目录中的 PNG、JPEG、GIF、WebP、TIFF 等图片可在标签页内打开，默认居中并适合窗口。双击在放大与适合窗口之间切换；普通滚轮和触控板双指滚动可平移，按住 ⌘ 再滚动可缩放。按住图片拖动可上下左右移动，也支持触控板捏合缩放。按 Escape 恢复适合窗口。工具栏提供缩放、适合窗口和 100% 显示。SVG 上方提供可调高度的预览区，支持缩放和适合窗口；编辑下方源码后，预览自动更新。双击 SVG 预览可打开前景大图，滚轮滚动图片，按住 ⌘ 滚轮缩放，按住图片拖动可平移，也支持触控板捏合。按 Escape 或关闭按钮返回，并恢复内嵌预览原来的缩放和滚动位置。

JSON 上方显示可折叠的结构树，点击值可定位到下方源码编辑；“格式化 JSON”整理缩进，保留长整数的原始精度，并可撤销。CSV 上方显示内嵌表格，点击单元格可定位原文编辑，支持带引号的逗号、换行和空值。较长列表分批显示，点击“显示更多”继续浏览。仅打开预览不会重写文件。

资料库与偏好设置

Markdown、HTML、PDF 和附件位于你打开的原目录。主题、模板、索引、标签页状态及恢复数据位于 ~/Library/Application Support/SimaQ。设置中可以打开主题和模板目录。内置两份普通 Markdown 模板，可直接编辑。

PDF 使用系统文本层检索，扫描 PDF 可阅读。HTML 使用作者的样式。打开含交互图表的本地报告后，可在文档菜单授予脚本信任，或撤销信任。修改报告文件后，原授权失效。

发布到微信公众号

打开 Markdown 页面，在“文件”菜单或页面右上角“…”选择“发布到微信公众号…”，也可以在命令面板搜索该命令。首次使用时在微信公众平台扫码并选择账号。窗口会打开新文章，填入标题和正文，供你设置封面、摘要和原创声明，并自行保存或发表。非微信托管的图片在原位置标记，需在后台补入。两个复制按钮会提示复制结果，并尝试填入对应的空白栏。如果该栏已有内容，可以点击要插入的位置后按 ⌘V 粘贴。

安装与构建

解压后双击 SimaQ.app，或拖入“应用程序”。开发环境需要 Xcode Command Line Tools（Swift 编译器和 macOS SDK）。源码在解压目录的 Source 中，在该目录执行 ./scripts/build.sh。包含预构建编辑资源的源码包可离线构建。构建产物在 build/SimaQ.app。此包使用本机临时签名，未经过 Apple 公证。
