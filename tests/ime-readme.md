# 中文输入法验收

`app-editing.js` 在应用的真实 WKWebView 中触发 `compositionstart`、`compositionupdate`、`input`、`compositionend`，并检查主题切换、YAML 折叠、源码切换与保存结果。事件的 `isTrusted` 为 `false`，这组测试验证编辑器的合成事件处理；它没有调用系统输入法，也没有验证候选窗。

系统输入法验收须在独立临时资料库中进行，且仅使用用户已经启用的中文输入源。不要修改系统输入源列表、快捷键或个人资料库。若当前没有可用的中文输入源，记录“未实测：无已启用的中文输入源”，不要将合成事件结果当作系统输入法结果。

1. 新建临时笔记，输入一段中文与一个 Markdown 管道表格。
2. 使用现有中文输入源，输入拼音并在候选窗可见时保存截图；选择一个非首位候选词。记录输入源名称、拼音、所选候选与最终文本。
3. 在正文输入第二个词，候选窗仍可见时切换主题；完成候选选择，核对只插入一次，光标位置正确。
4. 分别在正文、源码视图、表格单元格重复输入与候选选择；表格中按回车确定候选后，单元格不应提前结束编辑。
5. 保存、关闭、重新打开临时笔记，核对中文、表格和未编辑段落；一次撤销应还原最近一次已提交编辑。

只有候选窗出现、候选选择完成且保存后复核通过，结果才能标为“系统输入法实测通过”。截图、输入源与用例结果应与当次测试 JSON 一起保存。没有执行的步骤记录为“未实测”。
